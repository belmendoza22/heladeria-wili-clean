# Sistema de Gestión de Pedidos y Stock - Heladería Wili

Sistema web desarrollado con Django para gestionar pedidos y control de stock en una heladería.

## Tecnologías utilizadas

- Python
- Django
- SQLite
- HTML
- CSS

## Funcionalidades

- Registro de pedidos
- Gestión de sabores
- Control de stock
- Panel administrativo

## Instalación

1. Clonar el repositorio

git clone https://github.com/usuario/heladeria_wili.git

2. Entrar al proyecto

cd heladeria_wili

3. Crear entorno virtual

python -m venv env

4. Activar entorno

Windows:
env\Scripts\activate

5. Instalar dependencias

pip install -r requirements.txt

6. Ejecutar migraciones

python manage.py migrate

7. Ejecutar el servidor

python manage.py runserver
