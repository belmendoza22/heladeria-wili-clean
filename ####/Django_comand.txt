Django comandos
------------------------------------------------------------------------------------
(ctrl + '') -> abrir la terminal integrada
(.\venv\Scripts\activate) -> activar formato venv del entorno virtual
(cls) o (ctrl + L) -> para limpiar consola
(django-admin startproject) -> para crear un proyecto
(python manage.py startapp tasks) -> carpeta/documento para iniciar una aplicación
(python manage.py runserver) -> para ejecutar 
(ctrl + s) -> guardar un archivo
(ctrl + c) -> cancela la consola
